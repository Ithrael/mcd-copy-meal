# 麦麦抄作业

**朋友这份点法，在我这家店能用吗？保留具体餐品、套餐选件和份数，用自己的门店重新核价。**

适合收到朋友点餐攻略、想确认自己能否照着点的人，也适合想控制一顿饭预算的学生和上班族。支持单点、套餐和随心配；套餐里的汉堡、小食、饮料杯型也会一起保留。

![桌面演示界面，金额为示例，未实时核验](docs/images/demo-desktop.webp)

## 能怎么用

- **核验朋友的攻略**：粘贴本项目的分享链接或带链接的完整分享文案，先看点法，再选择自己的门店核价。当前支持结构化分享，任意文字攻略和截图识别尚未实现。
- **看懂核验结果**：原样点法通过核价、超出预算、缺少餐品或暂时无法核验分别展示；演示结果始终标注。失败或换店后撤掉旧价格，修改点法后标明结果属于修改后的搭配。
- **按预算找搭配**：选择必点餐品及饮料、小食要求，最多展示三份已核价结果。
- **套餐内自由改选**：按门店实际可选项换饮料、换小食、改份数，再调用官方计价。
- **发给朋友照着点**：复制具体点法和链接，或保存包含照片、门店、金额来源、核价时间与二维码的攻略图。
- **在自己的门店抄作业**：按名称重新匹配套餐和具体选件，重新核价；缺货显示缺项，超预算显示差额。

无需 Token 即可点击“体验换店核验（演示）”走完一次流程。本地真实模式连接麦当劳中国官方 MCP，不依赖 LLM API、数据库或前端构建。GitHub Pages 演示复用同一份界面与配餐规则，经过静态打包后在浏览器运行。

## 3 分钟开始

需要 Node.js 22 或 24。

```sh
npm ci
npm start
```

打开 http://127.0.0.1:3107 ，直接体验示例菜单。开发时使用 `npm run dev`。

真实核价：在页面点击“连接麦当劳”，填写你在 [麦当劳开放平台](https://open.mcd.cn/mcp) 申请的个人 MCP Token，再选择城市与门店。Token 只保留在本次页面会话中。

个人本地开发也可复制 `.env.example` 为 `.env.local`，填写 `MCD_MCP_TOKEN` 后重启。该文件不提交到 Git；不要把 Token 放进截图、日志、分享或公开服务配置。

## 一份作业如何复用

1. 设置 30 元预算，选择想吃的汉堡和薯条，生成搭配。
2. 点“改一下搭配”，在套餐里把饮料换成自己喜欢的杯型并重新核价。
3. 点“分享这份作业”或“保存攻略图”。
4. 朋友打开链接，或在首页“核验朋友的攻略”粘贴分享文案；能先看到套餐名称、各轮具体选件与份数，选择自己的门店后核验。
5. 目标门店缺项时，由朋友手动替换；不同门店的价格和券权益分别核验。

链接包含餐品、套餐选件、份数和预算，不包含 Token、门店编码、个人地址、优惠券标识或原店价格。旧版单品分享链接继续兼容。

| 人气经典随心配：麦香鸡＋可乐中杯 | ¥13.90 |
| 麦香鸡中套餐：麦香鸡＋中薯条＋可乐中杯 | ¥28.00 |

## 公网部署

已增加 [GitHub Pages 工作流](.github/workflows/pages.yml)，发布在线演示：配餐、修改套餐、分享和换演示门店均在浏览器完成，PNG 二维码也在浏览器生成。页面、分享文案和攻略图注明示例金额；在线站不接收 MCP Token。真实核价继续在本地版使用。**Pages 公开地址待部署成功并访问核验后补充。**

自行构建静态演示：`npm ci` 后运行 `npm run build:pages`，只发布 `dist/`。该目录不包含 Node 服务、环境文件或账户数据；不能直接把原始 `public/` 当成完整静态站上传。详细步骤见 [部署说明](docs/deploy.md)。

需要网页实时核价时，可另行使用现有 [Render 配置](render.yaml)和[Render 部署入口](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FIthrael%2Fmcd-copy-meal)。这属于完整 Node 服务，目前尚未发布。

公开服务不配置共享账户 Token，每位使用者填写自己的 Token；未连接的访客仍可体验明确标注的演示模式。

## 验证与接入

```sh
npm run check
npm test
npm run build:pages
npm run inspect:mcp
```

自动测试覆盖预算和套餐内部的必点约束、具体选件、默认特制、商品级券匹配、跨店编码匹配、缺货、价格单位、分享字段剔除及 HTTP 边界。真实 MCP 字段节选作为测试 fixture 保存；自动测试不联网，也不需要凭证。GitHub CI 配置在 Node 22、24 上执行检查与测试。

`inspect:mcp` 需要真实连接，只显示所用工具的输入 schema。接入通过官方 `@modelcontextprotocol/sdk`，使用 `query-nearby-stores`、`query-meals`、`query-meal-detail`、`query-store-coupons`、`calculate-price`。

[SKILL.md](SKILL.md) 是客户端技能入口，[mcp-config.example.json](mcp-config.example.json) 只提供环境变量占位符；变量展开方式取决于客户端。
