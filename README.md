# 麦麦抄作业

一份点餐攻略，可以生成、修改、分享，并按朋友自己的门店重新计价。

面向想控制一顿饭预算、保留喜欢餐品，也愿意把搭配分享给朋友的麦当劳用户。

## 首版功能

- 设置预算、必点餐品、小食与饮料要求，生成最多三份候选搭配。
- 手动替换餐品或调整份数后重新计价。
- 分享链接保留餐品名称、份数与预算；接收者换门店后重新匹配当前菜单。
- 分享遇到缺货时显示缺项，超预算时显示差额。
- 保存含门店、餐品、金额来源、核验时间和复用二维码的 PNG 攻略图。
- 无 Token 可完整体验演示模式；配置 Token 可进入真实接入流程。
- 手机和桌面均可使用，分享不需要数据库。

## 安装和启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm start
```

打开 http://127.0.0.1:3107 。开发时可以运行 `npm run dev`。

真实连接可在页面“连接麦当劳”中填写个人 Token；本地开发也可复制 `.env.example` 到 `.env.local` 后填写 `MCD_MCP_TOKEN`，重启服务。不要将 Token 发到聊天、提交到 GitHub 或放进分享内容。

```sh
npm run inspect:mcp
```

这会显示所用工具的当前输入 schema，方便按真实参数联调。2026-10-09 已使用有效 Token 完成官方门店、菜单、商品详情和计价联调；测试账户在测试门店没有可用券，商品级用券仍待有券账户验证。详细记录和边界见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。

## 使用示例

以下为演示模式示例。真实模式的菜单、规格名称和金额以所选门店返回为准。

1. 设置 30 元预算，选择“麦香鸡”和“薯条”为必点，点击“帮我搭一份”。
2. 点击“改一下搭配”，替换小食或饮料，再次计价。
3. 点击“分享这份作业”，通过系统分享或复制链接发给朋友。
4. 朋友打开链接，选择自己的门店，点击“按我的门店重算”。
5. 如果所选门店不售卖某个餐品，点击“手动替换餐品”；如果价格超预算，调整后再次核价。

本地地址只有运行服务的电脑可访问。面向朋友分享前，需要把服务部署到可访问的 HTTPS 地址；链接会自动使用当前网站的域名。服务器环境有完整交付代码，但本次尚未部署公网网址。

## 演示数据与图片

演示门店为虚拟门店，金额、优惠为独立测试数据，不代表当前餐厅价格。所有演示结果、攻略图都标注来源。餐品图片来自麦当劳公开菜单图片域名；具体来源保存在 `public/assets/sources.json`。图片只用于该非官方参赛作品展示，相关权利属于原权利人。

真实模式只生成无需套餐选件的单品组合，展示详情中的规格名称，并使用官方默认特制；需选件的套餐或饮料组合尚未实现。推荐结果来自有限候选核验，不宣称全局最低价。菜单展示价可能不同于计价结果，预算判断始终使用官方计价金额。

## Skill 与参赛

`SKILL.md` 可作为支持 Skill 的客户端技能入口，`mcp-config.example.json` 提供脱敏接入配置；环境变量占位符是否自动展开取决于客户端，实际 Token 只在本机客户端配置中填入。

官方 `CONTEST_DECLARATION.md` 已原样保存，真实 MCP 调用记录已更新。项目尚未公开或报名；需要对外分享时，再部署服务、公开仓库并按官方活动要求报名。此次开发使用 Codex，未使用 WorkBuddy，因此不提供虚构的 `workbuddy.md`。

## 文件

`server.js` 提供同源 API 和静态网页；`lib/recipes.js` 处理搭配与预算；`lib/mcd.js` 处理真实 MCP；`public/` 包含页面、分享编码和图片导出。项目不依赖数据库或前端构建工具。
