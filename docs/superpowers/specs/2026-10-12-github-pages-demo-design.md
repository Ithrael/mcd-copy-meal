# GitHub Pages 在线演示

用户已选择“GitHub Pages 演示版”。在线站点提供配餐、修改套餐、分享链接、换演示门店、缺项/超预算提示和攻略图导出；所有金额明确标注为演示值。真实 MCP 核价继续由现有本地 Node 版提供。

## 设计

- 使用同一份界面和现有配餐、套餐及分享代码，不另造推荐算法或菜单。
- Pages 模式的浏览器适配器复用 `lib/demo.js`、`lib/recipes.js` 与 `lib/meals.js`；不请求服务端 `/api/*`，不接收 MCP Token。
- 复用现有 qrcode 依赖在浏览器生成二维码。图片使用仓库已有演示素材，保持图与页面的金额来源标记。
- 资源、品牌首页和分享链接支持 `/mcd-copy-meal/` 子路径，二维码指向实际在线演示。
- 保留本地模式的连接、Token 会话、真实查询和官方核价流程。在线“使用真实核价”入口展示本地使用说明。
- 一个小型 esbuild 构建将浏览器代码打包；输出只含 HTML、CSS、JS、图片和 `.nojekyll`，不复制服务端、环境文件或真实响应。
- GitHub Actions 执行检查、测试和静态构建，再通过官方 Pages Actions 发布。仓库现有 CI 继续运行。

## 执行与验收

1. 增加静态适配与构建，调整项目子路径及演示文案。
2. 验证静态生成、分享、换店重算、超预算、缺项、套餐修改、PNG 与二维码；检查 390px 手机布局及原有 Node 版。
3. 构建产物检查通过后启用仓库 Pages，提交并推送，等待实际部署完成。
4. 访问 GitHub 返回的 HTTPS 地址完成浏览器检查，将真实体验链接写入 README、部署说明与项目主页。

此次不增加后端托管、浏览器直连 MCP、任意文字/截图识别、数据库或自动下单。上线以真实 HTTPS 访问和 Pages 部署记录为准。
