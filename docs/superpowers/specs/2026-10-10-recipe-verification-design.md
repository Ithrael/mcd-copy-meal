# 麦麦抄作业：朋友点法核验

用户已确认按推荐继续深化现项目：突出“朋友这份点法，在我这家店能用吗？”，先完成公开体验与真实券验证，再考虑任意文字攻略输入。

## 本次设计

- 首页明确生成点法与核验朋友点法两个入口；核验入口接收本项目的分享链接或带链接的分享文案。
- 沿用 v1/v2 分享结构、现有门店查询、餐品匹配和官方计价。链接只保存餐品、套餐选件、份数、预算与标题。
- 接收者先查看具体点法，再选自己的门店核验。结果明确显示原样可点、超出预算、缺少餐品、暂时无法核验。演示结果始终带演示标识。
- 核验失败、换店、切换连接及修改点法时，撤掉旧结果，避免把旧价格或修改后的点法当成原攻略核验成功。
- 复制文案和攻略图突出“你那里能用吗”，继续展示门店、核价时间与账户券条件。
- 保留预算搭配功能，保持 Node 与原生页面；沿用现有视觉。此次不增加截图识别、自由文本餐品解析、数据库或自动下单。

## 验证与发布

1. 改页面入口、核验状态和分享文案。
2. 执行现有检查与测试；浏览器检查导入链接、跨店核价、超预算、缺项、无效链接与手机布局。
3. 使用现有个人 Token 只读查询测试门店优惠券；空券、失败或未知结构如实记录，不自动领取或消费权益。
4. 用户“按照推荐”已授权继续公开体验交付。通过检查后公开当前项目仓库；部署平台向用户确认，取得选择与可用平台访问后发布 HTTPS 服务。公开服务不配置共享账户 Token。
5. 更新 README 与实测证据，仅写实际核验过的结果与公开地址；报名不在此次范围内。

## 完成标准

朋友能导入点法并理解核验结果；已有预算搭配不回归；真实券验证有明确结果；仓库可公开安装。公网部署须由实际 HTTPS 地址及访问检查证明，未部署时明确说明缺少的平台访问。
