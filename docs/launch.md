## 介绍文案

今天想吃麦香鸡和薯条，30 元以内怎么搭？

我做了“麦麦抄作业”：按你选的店查当前菜单，把单点、套餐、随心配放在一起核价。套餐里选了什么汉堡、哪种饮料、什么杯型，都能改，也能原样发给朋友。朋友用自己的门店重算，缺货会提示，不拿别家店的旧价格当报价。

无需 Token 可以先体验标注清楚的演示；连接自己的麦当劳 MCP Token 后可实时核价。只查菜单和价格，不自动下单。
