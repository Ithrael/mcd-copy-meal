麦麦抄作业：朋友这份点法，在我这家店能用吗？保留具体餐品和套餐选件，用自己的门店重新核价。

## 介绍文案

朋友发来的麦当劳点法，到了你这家店还能用吗？

我做了“麦麦抄作业”：粘贴朋友分享的攻略链接或完整文案，保留具体餐品、份数和套餐里的饮料杯型，换到自己的店核价。原样可核价、超预算、缺项和暂时无法核验分别展示；改了点法，结果也会明确注明。也可以按预算搭一份，把点法和核验时间发给朋友继续验证。

无需 Token 可以在线体验标注清楚的演示；下载项目在本地运行后，连接自己的麦当劳 MCP Token 可实时核价。只查菜单和价格，不自动下单。

体验：https://ithrael.github.io/mcd-copy-meal/ （在线演示，示例门店与金额）
源码：https://github.com/Ithrael/mcd-copy-meal

如果这份作业帮你少纠结了一次午饭，欢迎收藏或给项目一个 Star，也欢迎告诉我哪个点法不好用。

## 30 秒演示脚本

| 时段 | 画面与信息 |
| --- | --- |
| 0–5 秒 | 打开朋友的攻略：这份点法，我这里能用吗？ |
| 5–12 秒 | 查看餐品、份数、套餐选件；选择自己的门店。 |
| 12–18 秒 | 展示核验状态、所选门店与金额；实时等待不剪成即时返回，演示模式明确标注。 |
| 18–25 秒 | 改预算或套餐选件，展示超额或修改后结果，再分享给朋友。 |
| 25–30 秒 | 展示实际导出的攻略图和源码入口。 |

录制不展示 Token 输入、请求头或账户资料。展示 27.40 元案例时，注明“上海黄浦华旭国际大厦餐厅，2026-10-09 本次核价”；不要用“全国最低”“永远这个价格”等未经核实的描述。
