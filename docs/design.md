# 麦麦抄作业首版

用户已确认的目标：做一个实用、便于分享和复用的点餐攻略工具。

## 流程

选择门店、预算和必点餐品 → 生成最多三份搭配 → 修改搭配并重新计价 → 分享链接或保存含复用二维码的攻略图片 → 接收者选择自己的门店 → 按本地菜单重新匹配和计价。本地预览的分享会说明链接只能在本机打开。

首版采用到店取餐，一人份搭配；在结果中展示商品、总价、预算余额和价格来源。必点餐品不可被静默替换，无解时说明原因。

## 交付

手机优先网页、Node 服务、麦当劳 MCP 接入、可加载的参赛 Skill 和参赛文档。一个页面承担生成和复用流程。攻略编码到 URL fragment 中，内容限于餐品名称、数量、预算及标题，不携带 Token、个人优惠券、账户或收货信息。无需数据库。

未提供 Token 时显示演示菜单和示例金额。真实模式使用接收者自己的 Token 或本地开发环境的 Token，查询门店、菜单、餐品详情和门店优惠券，并用官方 calculate-price 核价。真实调用失败时显示失败，不回退伪造价格。网页只执行只读工具。

## 视觉

红色 #D9252A、黄色 #FFC72C、白色 #FFFFFF、文字 #29241E、背景 #F6F7F8、边框 #E5E7EB。主体使用中文系统无衬线字体，金额采用 DIN Alternate/Arial。桌面左侧选择、右侧搭配，手机顺序堆叠。用订单小票表达可照着点的攻略，用真实餐品图片帮助识别。

## 验证

验证预算约束、必点保留、无解、精确金额、分享解析和跨门店匹配；用模拟 MCP 返回验证工具参数与异常处理；浏览器验证生成、修改、分享、重新核价、图片导出和手机视口。未提供 Token 时如实记录真实联调未完成。
